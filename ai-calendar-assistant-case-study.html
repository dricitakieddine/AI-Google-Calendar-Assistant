AI Google Calendar Assistant

Natural-language scheduling, automated.

An AI-powered scheduling assistant that turns natural-language requests into automated Google Calendar actions — built end to end with an LLM agent, n8n orchestration, and the Google Calendar API.

How it works

From a sentence to a scheduled event.

01

User

The person types or speaks a request in plain language — no form, no fields.

02

Natural-language request

The request is captured as-is: "Schedule a meeting with Ahmed tomorrow at 3 PM."

03

AI / OpenAI

An LLM agent reads the request and interprets what's actually being asked.

04

Intent and data extraction

The model pulls out the structured pieces: person, date, time, and event type.

05

n8n workflow

n8n receives the structured data and orchestrates the next steps and API calls.

06

Google Calendar API

The workflow calls the Calendar API to create or update the event.

07

Confirmation

The assistant confirms back to the user that the event was created.

Technical breakdown

n8n acts as the orchestration layer for the whole assistant. When a request comes in, the AI agent interprets it and converts the free-text sentence into structured information — who, when, and what.

The workflow then calls the Google Calendar API to perform the requested action, and returns a confirmation to the user.

Because the logic is split into discrete steps — understanding, extraction, execution, confirmation — each part of the pipeline can be tested, replaced, or extended on its own.
